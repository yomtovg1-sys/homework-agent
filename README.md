# סוכן שיעורי בית יומי

בימים א'–ו' בשעה 15:30 (שעון ישראל) הסוכן:
1. מושך את שיעורי הבית של **שלו** ממשו"ב ושל **נועם** מוובטופ.
2. מסכם אותם עם Claude להודעה קצרה בעברית.
3. שולח את ההודעה לוואטסאפ שלך דרך CallMeBot (חינם).

הסוכן רץ ב-GitHub Actions, כך שלא צריך מחשב דלוק.

## הגדרה חד-פעמית

### 1. מפתח וואטסאפ (CallMeBot)
1. היכנסי ל-https://www.callmebot.com/blog/free-api-whatsapp-messages/ ושמרי באנשי הקשר את המספר שמופיע שם.
2. שלחי לו בוואטסאפ: `I allow callmebot to send me messages`
3. תקבלי הודעה חזרה עם `apikey`.

### 2. מפתח Claude API
1. היכנסי ל-https://console.anthropic.com והתחברי (או הירשמי).
2. בתפריט **API Keys** תראי אם כבר יש לך מפתחות. אם אין, לחצי **Create Key**.
3. ב-**Billing** הוסיפי אמצעי תשלום וטעני קרדיט מינימלי ($5 יספיקו לחודשים רבים).

שימי לב: מנוי Claude.ai (Pro/Max) הוא דבר נפרד ולא כולל מפתח API.

### 3. סמל המוסד במשו"ב
סמל המוסד הוא מספר בן 6 ספרות. רואים אותו במסך הכניסה של משו"ב כשבוחרים את בית הספר, או באתר בית הספר.

### 4. הכנסת הסודות ל-GitHub
בריפו: **Settings → Secrets and variables → Actions → New repository secret**, והוסיפי:

| שם | מה לשים |
|---|---|
| `MASHOV_SCHOOL_ID` | סמל המוסד של שלו |
| `MASHOV_USERNAME` | שם המשתמש של שלו במשו"ב |
| `MASHOV_PASSWORD` | הסיסמה של שלו במשו"ב |
| `WEBTOP_USERNAME` | שם המשתמש של נועם בוובטופ |
| `WEBTOP_PASSWORD` | הסיסמה של נועם בוובטופ |
| `WHATSAPP_PHONE` | המספר שלך בפורמט בינלאומי, למשל `+972501234567` |
| `CALLMEBOT_API_KEY` | המפתח שקיבלת מ-CallMeBot |
| `ANTHROPIC_API_KEY` | מפתח ה-Claude API |

### 5. בדיקה
**Actions → Daily homework summary → Run workflow**.
- סמני `dry_run` כדי לראות את ההודעה בלוג בלי לשלוח.
- בלי הסימון, ההודעה תישלח לוואטסאפ מיד.

## הערות
- משו"ב ווובטופ לא מספקים API רשמי, והסוכן משתמש בממשקים שהאפליקציות שלהם משתמשות בהם. אם הם ישתנו, ייתכן שיהיה צורך לעדכן את הקוד.
- אם אחת המערכות לא זמינה, ההודעה עדיין תישלח ותציין שלא הצלחנו למשוך את הנתונים של אותו ילד.
- GitHub מריץ משימות מתוזמנות לפעמים באיחור של כמה דקות.
